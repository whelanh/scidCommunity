scidCommunity menus

File

  • [New]: Creates a new empty scidCommunity database.
  • [Open]: Opens an existing scidCommunity database.
  • [Finder]: Opens the File Finder.
  • [Bookmarks]: Bookmarks and bookmark functions.
  • [Open Base as Tree]: Opens a database as a tree view.
  • [Open Recent Base as Tree]: Opens a recent database as a tree view.
  • [Open Lichess Tournament]: Opens a Lichess tournament for analysis.
  • [Import Lichess Games]: Imports games from Lichess.
  • [Import Chess.com Games]: Imports games from Chess.com.
  • [Exit]: Exits scidCommunity.

Database

  • [Close]: Closes the current scidCommunity database.
  • [Load at Startup]: Toggles whether the current database loads at startup.
  • [Copy All Games]: Submenu to copy all games to another database.
    • [New Database]: Creates a new database and copies all games.
    • [Other Databases]: Lists available databases to copy to.
  • [Export Filter]: Exports games matching the current filter.
    • [PGN]: Exports to PGN format.
    • [HTML]: Exports to HTML format.
    • [HTML with JavaScript]: Exports to interactive HTML format.
  • [Import File]: Submenu to import PGN files into databases.
  • [Maintenance]: Database maintenance utilities.
    • [Maintenance Window]: Opens/closes the maintenance window.
    • [Compact Database]: Compacts the current database.
    • [Classify Games]: Classifies all games with ECO codes.
    • [Name Editor]: Opens/closes the name editor window.
    • [Strip Tags]: Strips unwanted tags from games.
    • [Delete Twins]: Marks twin games for deletion.
    • [Update Twin Checker]: Updates the twin checker.
    • [Cleaner]: Opens the database cleaner window.
  • [Name Maintenance]: Spell checking and rating allocation for names.
    • [Player Names]: Spell checks player names.
    • [Event Names]: Spell checks event names.
    • [Site Names]: Spell checks site names.
    • [Round Names]: Spell checks round names.
    • [Add Elo Ratings]: Allocates Elo ratings to players.
  • [Base 1/2/3/...]: These commands let you switch between available database slots and the clipbase database.

Edit

  • [Undo]: Undoes the last action.
  • [Redo]: Redoes the previously undone action.

  • [Setup Board]: Sets the starting position for the current game.
  • [Copy Board as FEN]: Copies the current board position as FEN to clipboard.
  • [Paste Board from FEN]: Pastes a board position from FEN in clipboard.
  • [Copy Game as PGN]: Copies the current game as PGN to clipboard.
  • [Paste Game from Clipboard]: Pastes a game from clipboard in PGN format.

  • [Strip]: Strips elements from the current game.
    • [Comments]: Strips all comments from the current game.
    • [Variations]: Strips all variations from the current game.
    • [Beginning]: Strips moves from the beginning to current position.
    • [End]: Strips moves from current position to the end.

  • [Reset Clipbase]: Empties the clipbase so it contains no games.
  • [Copy to Clipbase]: Copies the current game to the clipbase database.
  • [Paste from Clipbase]: Pastes the active game of the clipbase to be the active game of the current database.

Game

  • [New Game]: Resets the active game to an empty state, discarding any unsaved changes.
  • [Reload this game]: Reloads the current game, discarding any changes made.

  • [Save: Replace game]: Saves the current game, replacing its original version in the database.
  • [Save: Add new game]: Saves the current game as a new game, appending to the end of the database.
  • [Export Current Game]: Exports the current game to various formats.
    • [PGN]: Exports to PGN format.
    • [HTML]: Exports to HTML format.
    • [HTML with JavaScript]: Exports to interactive HTML format.

  • [Load First Game]: Loads the first game in the filter.
  • [Load Previous Game]: Loads the previous game in the filter.
  • [Load Next Game]: Loads the next game in the filter.
  • [Load Last Game]: Loads the last game in the filter.
  • [Load Random Game]: Loads a random game from the filter.

  • [Identify opening]: Finds the deepest position in the current game that is in the ECO file.
  • [Goto move number]: Goes to the specified move number in the current game.
  • [Find novelty]: Finds the first move of the current game that has not been played before.

Search

  • [Current board]: Searches for the current board position.
  • [Header]: Searches by header information such as player names.
  • [Material/Pattern]: Searches by material or chessboard patterns.

  • [Player List]: Opens/closes the player list window.
  • [Tournament Finder]: Opens/closes the Tournament Finder window.

  • [Using search file]: Searches using settings from a SearchOptions file.

Play

  • [Serious Game]: Configures and starts a serious game against an engine.
  • [Tactical Game]: Configures and starts a tactical game against an engine.
  • [FICS Training]: Configures connection to the Free Internet Chess Server.
  • [Training]: Training submenu.
    • [Openings Training]: Configures openings training.
    • [Tactics Training]: Configures tactics training.
    • [Review Game]: Starts game review mode.
    • [Calvar Training]: Configures calculation of variations training.

Windows

  • [Comment Editor]: Opens/closes the Comment Editor window.
  • [PGN window]: Opens/closes the PGN window.
  • [Show Game Info]: Toggles display of game information panel.

  • [Game List window]: Opens/closes the Game List window.
  • [Database Switcher]: Opens/closes the Database Switcher window, which lets you switch to another database or copy games between databases easily.
  • [Crosstable]: Constructs a tournament crosstable for the current game.
  • [ECO Browser]: Opens/closes the ECO Browser window.
  • [Statistics window]: Opens/closes the Filter statistics window which gives a win/loss summary of the games in the filter.
  • [Tree window]: Opens/closes the tree window.
  • [Book window]: Opens/closes the opening book window.
  • [Score Graph]: Refreshes the score graph.

Tools

  • [Configure Engines]: Opens the engine configuration dialog to set up chess engines.
  • [Start Engine 1]: Starts the first chess analysis engine.
  • [Start Engine 2]: Starts the second chess analysis engine.
  • [Analysis Window]: Opens the analysis window.

  • [Filter Graph]: Opens/closes the filter graph window.
  • [Absolute Filter Graph]: Opens/closes the absolute filter graph window.
  • [Opening Report]: Generates an opening report for the current position.
  • [Piece Tracker]: Opens the piece tracker window.
  • [Book Tuning]: Opens the book tuning window.
  • [Download TWIC]: Downloads the latest This Week In Chess games.
  • [Connect Hardware]: Hardware connection submenu.
    • [Configure]: Configures hardware connections.
    • [Input Engine Connect]: Connects/disconnects input engine.
    • [Novag Citrine Connect]: Connects/disconnects Novag Citrine board.

  • [Player Information]: Displays player information for the White or Black player of the current game.
  • [Player Report]: Opens the player report dialog.
  • [Rating Graph]: Displays the rating graph.

Options

  • [Language]: Submenu to select the interface language.
  • [Theme]: Submenu to select the GUI theme.
  • [Configure Scid]: Opens the preferences dialog.
  • [Resources]: Opens the resources configuration dialog.
  • [Export]: Export format settings submenu.
    • [PGN file text]: Sets PGN export text options.
    • [HTML file text]: Sets HTML export text options.

  • [Full Screen]: Toggles full screen mode.
  • [Dock Windows]: Toggles window docking.
  • [Save Layout]: Saves the current window layout.
  • [Restore Layout]: Restores a saved window layout.

  • [Save Options]: Saves the current options to the file "~/.scid/scidrc" (or scid.opt in the directory of the scidCommunity executable programs for Windows users); this file is loaded each time you start up scidCommunity.
  • [Auto Save]: Toggles automatic saving of options on exit.

Help

  • [Contents]: Opens the help contents page.
  • [Index]: Opens the help index.
  • [Quick Guide]: Opens the quick start guide.
  • [Hints]: Opens the hints page.
  • [Contact]: Opens the contact information page.
  • [Tip of the Day]: Shows the tip of the day window.
  • [About]: Shows information about scidCommunity.
